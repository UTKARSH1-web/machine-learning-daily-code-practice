# Decision Tree

Decision Tree is a supervised machine learning algorithm used for:

- Classification
- Regression

It works like a tree structure where decisions are made based on conditions.

---

# Important Terms

## Root Node
The starting node of the tree.

## Leaf Node
The final output node.

## Splitting
Dividing the dataset into smaller subsets.

## Entropy
Measures impurity in the dataset.

Entropy Formula:

Entropy = -Σ p(x) log2 p(x)

## Gini Impurity

Gini = 1 - Σ(p²)

## Information Gain
Reduction in entropy after splitting.

---

# Advantages

- Easy to understand
- Easy visualization
- No feature scaling required
- Works with numerical and categorical data

---

# Disadvantages

- Overfitting problem
- Unstable sometimes

---

# Applications

- Loan prediction
- Fraud detection
- Disease prediction
- Recommendation systems
