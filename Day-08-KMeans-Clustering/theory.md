# K-Means Clustering

K-Means is an unsupervised machine learning algorithm.

It groups similar data points into clusters.

---

# How K-Means Works

1. Choose number of clusters (K)
2. Select random centroids
3. Assign points to nearest centroid
4. Update centroids
5. Repeat until convergence

---

# Important Parameter

## n_clusters

Defines number of clusters.

Example:

n_clusters = 4

---

# Advantages

- Simple and fast
- Easy to understand
- Works well on large datasets

---

# Disadvantages

- Sensitive to outliers
- Need to define K value
- Different results sometimes

---

# Applications

- Customer segmentation
- Image compression
- Recommendation systems
- Market analysis

---

# Conclusion

K-Means is one of the most popular clustering algorithms in machine learning.
