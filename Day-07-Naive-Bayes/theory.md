# Naive Bayes

Naive Bayes is a supervised machine learning algorithm based on Bayes Theorem.

It is mainly used for classification problems.

---

# Bayes Theorem

P(A|B) = [P(B|A) * P(A)] / P(B)

Where:

- P(A|B) = Posterior Probability
- P(B|A) = Likelihood
- P(A) = Prior Probability
- P(B) = Evidence

---

# Why is it called Naive?

Because it assumes all features are independent from each other.

---

# Types of Naive Bayes

## Gaussian Naive Bayes
Used for continuous data.

## Multinomial Naive Bayes
Used for text classification.

## Bernoulli Naive Bayes
Used for binary features.

---

# Advantages

- Fast algorithm
- Easy to implement
- Works well on small datasets
- Good for text classification

---

# Disadvantages

- Assumes feature independence
- Lower accuracy sometimes

---

# Applications

- Spam detection
- Sentiment analysis
- News classification
- Recommendation systems

---

# Conclusion

Naive Bayes is one of the fastest and simplest classification algorithms in machine learning.
