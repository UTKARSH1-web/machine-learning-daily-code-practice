# Confusion Matrix

A Confusion Matrix is a table used to evaluate classification models.

---

# Structure

                Predicted

              Negative Positive

Actual Negative   TN      FP

Actual Positive   FN      TP

---

# Terms

## True Positive (TP)

Actual Positive
Predicted Positive

Correct Prediction

---

## True Negative (TN)

Actual Negative
Predicted Negative

Correct Prediction

---

## False Positive (FP)

Actual Negative
Predicted Positive

Wrong Prediction

Also called:

Type I Error

---

## False Negative (FN)

Actual Positive
Predicted Negative

Wrong Prediction

Also called:

Type II Error

---

# Example

Actual:

Pass
Pass
Fail
Fail

Predicted:

Pass
Fail
Pass
Fail

Result:

TP = 1
FN = 1
FP = 1
TN = 1

---

# Why Use Confusion Matrix?

Provides deeper insights than accuracy.

---

# Applications

- Medical Diagnosis
- Spam Detection
- Fraud Detection
- Student Performance Prediction

---

# Conclusion

Confusion Matrix is the foundation for Precision, Recall, and F1 Score.
