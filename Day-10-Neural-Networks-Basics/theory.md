# Neural Networks Basics

Neural Networks are machine learning models inspired by the human brain.

They are the foundation of Deep Learning.

---

# Structure of Neural Network

Input Layer
↓
Hidden Layer
↓
Output Layer

---

# Components

## Neuron

Basic unit of a neural network.

## Weights

Importance assigned to inputs.

## Bias

Additional parameter used to improve learning.

## Activation Function

Determines whether a neuron should activate.

Examples:

- ReLU
- Sigmoid
- Tanh

---

# How Neural Networks Work

1. Input data enters network
2. Data passes through hidden layers
3. Weights are adjusted
4. Output is generated
5. Error is minimized using training

---

# Disadvantages
