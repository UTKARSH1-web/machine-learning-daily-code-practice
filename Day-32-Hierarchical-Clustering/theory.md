# Hierarchical Clustering

Hierarchical Clustering groups similar data into a hierarchy.

---

# Types

1. Agglomerative (Bottom-Up)

2. Divisive (Top-Down)

---

# Agglomerative Workflow

Every point starts as its own cluster.

↓

Nearest clusters merge.

↓

Repeat until required number of clusters.

---

# Dendrogram

A tree diagram showing cluster merging.

Higher merge height = Less Similar

Lower merge height = More Similar

---

# Linkage Methods

- Single
- Complete
- Average
- Ward

Ward is most commonly used.

---

# Advantages

- Easy to visualize
- No training required
- Good for small datasets

---

# Disadvantages

- Slow for large datasets
- Sensitive to noise

---

# Applications

- Customer Segmentation
- Biology
- Document Clustering
- Image Segmentation

---

# Conclusion

Hierarchical Clustering creates a tree of clusters and helps visualize relationships using a dendrogram.
