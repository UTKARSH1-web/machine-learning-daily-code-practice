# Support Vector Machine (SVM)

SVM is a supervised machine learning algorithm used for classification and regression problems.

It works by finding the best boundary (hyperplane) between classes.

---

# How SVM Works

1. Finds the optimal hyperplane
2. Maximizes margin between classes
3. Uses support vectors for decision making

---

# Important Terms

## Hyperplane

Decision boundary separating classes.

## Support Vectors

Nearest data points to hyperplane.

## Margin

Distance between hyperplane and support vectors.

---

# Kernel Types

## Linear Kernel

Used for linearly separable data.

## Polynomial Kernel

Used for complex data patterns.

## RBF Kernel

Most commonly used kernel.

---

# Advantages

- High accuracy
- Effective in high dimensional data
- Works well for classification

---

# Disadvantages

- Slow on large datasets
- Hard to visualize
- Sensitive to parameter tuning

---

# Applications

- Face detection
- Image classification
- Text classification
- Medical diagnosis

---

# Conclusion

SVM is one of the most powerful classification algorithms in machine learning.
