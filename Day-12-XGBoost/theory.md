# XGBoost (Extreme Gradient Boosting)

XGBoost is an advanced implementation of Gradient Boosting.

It is designed for speed, performance, and scalability.

---

# Why XGBoost?

- Faster training
- Better accuracy
- Regularization support
- Handles missing values

---

# How XGBoost Works

1. Train first tree
2. Calculate errors
3. Train next tree on errors
4. Add regularization
5. Repeat until improvement stops

---

# Important Parameters

## n_estimators

Number of trees

## learning_rate

Contribution of each tree

## max_depth

Maximum tree depth

---

# Advantages

- High performance

- Fast training
