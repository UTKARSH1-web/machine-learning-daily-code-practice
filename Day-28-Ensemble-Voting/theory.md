# Ensemble Learning

Ensemble Learning combines multiple machine learning models to improve performance.

---

# Basic Idea

Many Models

↓

One Strong Model

---

# Voting Classifier

Combines predictions from multiple classifiers.

---

# Types

## Hard Voting

Majority Vote

Example:

Tree → Pass

KNN → Pass

NB → Fail

Result:

Pass

---

## Soft Voting

Average Probabilities

Example:

0.80

0.70

0.60

Average:

0.70
