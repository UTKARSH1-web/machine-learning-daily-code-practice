# K-Nearest Neighbors (KNN)

KNN is a supervised machine learning algorithm used for classification and regression.

It works by finding the nearest data points to make predictions.

---

# How KNN Works

1. Choose value of K
2. Calculate distance
3. Find nearest neighbors
4. Take majority vote
5. Predict output

---

# Important Parameter

## n_neighbors

Defines number of nearest neighbors.

Example:

n_neighbors = 3

---

# Distance Metrics

## Euclidean Distance

Most commonly used distance formula.

Distance Formula:

d = √((x2-x1)² + (y2-y1)²)

---

# Advantages

- Easy to understand
- Simple implementation
- Good for small datasets

---

# Disadvantages

- Slow on large datasets
- Sensitive to noise
- Requires feature scaling

---

# Applications

- Recommendation systems
- Image recognition
- Medical diagnosis
- Pattern detection

---

# Conclusion

KNN is one of the simplest and beginner-friendly machine learning algorithms.
